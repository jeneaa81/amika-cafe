# Amika Café (Cricova) — Digital TV Menu Board & Guest App

Комплексная цифровая экосистема для локальной кофейни третьей волны **Amika Café** (Молдова, г. Крикова, ул. Друмул Виилор 10).

Включает автономный **Digital TV Menu Board** для Smart TV в зале, мобильное веб-приложение / Telegram Mini App гостя с предзаказом и цифровой программой лояльности, а также экраны бариста и администратора с облачной синхронизацией в реальном времени.

## ☕ Архитектурные особенности

### 1. Автономный TV Menu Board (`public/tv.html`)
- **Стандарт чистого ES5**: написан на строгом ES5 без синтаксиса ES6 (`let`, `const`, `=>`, шаблонные строки, модули) для 100% совместимости с браузерами Smart TV LG webOS 3.0+ (Chromium 38–68).
- **Безопасный CSS**: исключены современные директивы `gap:` во flexbox, `inset: 0`, `space-evenly`. Использованы кроссбраузерные префиксы `-webkit-box-flex`, `-webkit-flex`, вендорные отступы.
- **Аппаратное сглаживание углов**: карточки с радиусом `26px` снабжены маской `-webkit-mask-image: -webkit-radial-gradient(white, black)` и `background-clip: padding-box`, что исключает артефакты отсечения углов тенями.
- **Двуязычие**: мгновенное переключение RO / RU.
- **Без встроенных эмодзи**: все иконки (чашка, листок, сердце, часы, капли) реализованы на чистых SVG, гарантируя четкость на экранах высокого разрешения.

### 2. Умные темы оформления (Day / Night)
- **Дневная тема («Botanical Warm Cream»)**:
  - Фоновый рисунок: `tv_bg_day.jpg` с обрамлением ветвями оливы и эвкалипта.
  - Карточки меню: тёплый кремово-песочный оттенок `rgba(244, 217, 196, 0.97)` (`#f4d9c4`) в точном соответствии с интерьером кофейни.
  - Акценты: оливковый цвет часов `#556b2f` и бейджа `Specialty Coffee`.
- **Вечерняя тема («Evening Lounge / Dark Roast»)**:
  - Фоновый рисунок: `tv_bg_night.jpg` в тонах темного эспрессо и теплого вечернего боке.
  - Карточки меню: глубокий антрацит `rgba(24, 20, 18, 0.88)` с золотисто-оливковыми ценниками `#9bb155` и акцентами.
- **Режимы переключения темы**:
  - `auto_sunset` — астрономический алгоритм расчета времени восхода и заката для Крикова (47.139° N, 28.862° E) с переходом на вечернюю тему за 15 минут до заката.
  - `auto_schedule` — настраиваемый диапазон рабочих дневных часов (по умолчанию 08:00 – 17:00).
  - `day` / `night` — принудительная ручная фиксация.

### 3. Точное молдавское время (EET / UTC+2)
- Алгоритм часов высчитывает текущее время из UTC-эпохи миллисекунд с автоматическим распознаванием перехода на зимнее время (UTC+2 с последнего воскресенья октября) и летнее время (UTC+3), исключая сбои встроенного часового пояса Smart TV.

### 4. Двойной контур отказоустойчивой облачной синхронизации
- **Первичный контур (Supabase)**: долгосрочное облачное хранилище конфигурации меню (`menu_config`, строка `id='current'`).
- **Вторичный контур (Real-time Relay)**: тройной кластер европейских push-реле (Франция, Германия, глобальный через `ntfy.sh`) для мгновенного отклика ТВ при смене темы или цен без задержек кэширования.
- **Локальный контур**: `BroadcastChannel('amika_tv_bus')` и `localStorage` для мгновенной синхронизации окон на одном устройстве.

## 🛠 Технологический стек

- **Core Frontend**: React 19, TypeScript, Vite
- **Стилизация**: Tailwind CSS v4, Lucide React
- **База данных**: Supabase (PostgreSQL / REST API / SSE)
- **Звуковые эффекты**: Web Audio API (мелодичный колокольчик бариста без внешних тяжелых mp3)
- **CI / CD**: GitHub Actions / GitHub Pages (ветки `main` и `gh-pages`)

## 🚀 Локальный запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Проверка типов и линтинг
npm run lint

# Проверка совместимости tv.html для Smart TV
node scripts/verify_tv.cjs

# Продакшен-сборка
npm run build
```
